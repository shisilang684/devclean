## What counts as progress

- A star is a stranger deciding the tool is worth remembering.
- npm downloads measure intent; stars measure appreciation.
- A GitHub issue from a stranger is worth more than ten stars: it means they ran it.

## Conversion check

If impressions are high but stars are low, the README first screen is the problem.
If stars are high but downloads are low, the install path is the problem.
